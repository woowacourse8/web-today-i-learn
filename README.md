# 🚀 Today I Learn (TIL) 페이지 만들기

우아한테크코스 과정 중 진행한 웹 페이지 뼈대 잡기 및 꾸미기 프로젝트입니다. HTML, CSS, JavaScript의 역할을 이해하고, 나만의 소개 페이지와 TIL 기록 공간을 직접 구현합니다.

---

## ⛳️ 학습 목표
* 웹 페이지의 구성 요소(HTML, CSS, JS)의 각각의 역할 이해
* HTML 시맨틱 태그를 활용한 적절한 웹 페이지 구조 설계
* CSS 선택자와 레이아웃(Grid/Flexbox)을 활용한 시각적 스타일링
* JavaScript DOM 제어 및 이벤트 리스너를 활용한 동적 기능 구현

---

## 🛠 구현할 기능 (Checklist)

### 1단계: HTML (뼈대 잡기)
- [ ] **프로필 영역**: 나를 가장 잘 소개하는 사진(`<img>`), 닉네임, 한 줄 소개 구성
- [ ] **기본 정보**: 이름, MBTI, 취미 등을 표(`<table>`) 형태로 정리
- [ ] **자기소개**: 단락(`<p>`)으로 소개 글을 작성하고 관련 링크(`<a>`) 연결
- [ ] **나만의 갤러리**: 자유 주제로 사진 9장 정사각형 배치
- [ ] **인생 작품**: 목록(`<ul>` 또는 `<ol>`) 형태로 최소 2가지 소개 (영상 `<video>`/`<iframe>` 1개 이상 포함)

### 2단계: CSS (스타일링)
- [ ] 외부 스타일시트(`.css`)로 분리하여 `<link>` 태그로 연결
- [ ] 태그, 클래스(`.`), ID(`#`) 선택자 각각 1회 이상 사용
- [ ] 나만의 갤러리 이미지 9장을 `CSS Grid` 또는 `Flexbox`를 활용하여 배치
- [ ] 제공된 템플릿 레이아웃 기반으로 자유롭게 커스텀 스타일링

### 3단계: JavaScript (동작 추가)
- [ ] 외부 스크립트(`.js`)로 분리하여 `<script>` 태그로 연결
- [ ] TIL 섹션에 작성 폼(`<form>`, `<input>`, `<textarea>`, `<label>`) 추가
- [ ] 등록 버튼(`<button>`) 클릭 시 이벤트 리스너를 통해 입력 내용을 TIL 목록에 추가 (`DOM` 제어)

### 4단계: 배포 및 공유
- [ ] GitHub Pages (또는 다른 플랫폼)를 활용하여 웹 사이트 배포
- [ ] 완성된 홈페이지 링크 및 새롭게 배운 개념 공유
